# NITUL Games

A static browser-games website and project hub by Nitul Deka.

## Features
- Browser games and searchable game cards
- Responsive dark gaming layout
- Project links to Krishti AI and Zubeen Player
- Standalone SAYAVIBE music-player page

## Deploy on Render (Static Site)
1. Push the contents of this repository to GitHub.
2. In Render, choose **New → Static Site** and connect the repository.
3. Set the **Publish Directory** to `.` (the root directory containing `index.html`).
4. No build command is required for the main static site.
5. Deploy and test the home page, each game, and the project links.

## Project links
- Krishti AI: https://krishti-ai-1.onrender.com
- Zubeen Player: https://zubeen-player-jndf.onrender.com

Note: the project links point to externally hosted sites; this repository does not contain their server-side source code.
